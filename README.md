# İslam Ajandası V1

Kalp Yolculuğu'ndan tamamen bağımsız, telefon ana ekranına eklenebilen PWA.

## GitHub Pages kurulumu
1. GitHub'da `islam-ajandasi` adlı **public** depo oluşturun.
2. Bu klasördeki **7 dosyayı** (ZIP dosyasını değil) deponun kök dizinine yükleyin ve commit edin.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Yayın adresi: `https://asbaltaci.github.io/islam-ajandasi/` (GitHub Pages yayınlandıktan sonra).
5. iPhone Safari → Paylaş → Ana Ekrana Ekle. Android Chrome → Menü → Ana ekrana ekle.

## Kapsam
PDF'deki hatim/zikir çizelgeleri dijital takip olarak uyarlanmıştır; orijinal PDF sayfaları veya kitap metinleri uygulamaya eklenmemiştir. Kişisel kayıtlar tarayıcı localStorage alanında tutulur; JSON yedeği alınabilir. İnternetsiz kullanım için ilk kurulumda internet gereklidir.

## Sınırlar
Bu ilk sürüm PDF'nin birebir tasarım kopyası değildir; Esmâü'l-Hüsnâ'nın ayrıntılı metinleri ve PDF'deki tüm açıklamalar henüz eklenmedi. 1.000'lik kutular tek dokunuşla tamamlanan birer **bölüm** olarak takip edilir; her tekrar otomatik sayılmaz.
