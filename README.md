# İslam Ajandası V2

Bağımsız PWA. PDF’nin 28 sayfası için içerik rehberi ve dijital takip alanları. V1 zikir, hatim, namaz, oruç, not ve yedek kayıtları korunur.

V2: 99 Esmâü’l-Hüsnâ işaretleme, peygamberler haritası, dua/niyet, namaz sonrası zikir önerileri, tesirli zikirler, 46 günlük kaza namazı çizelgesi ve 28 sayfalık içerik rehberi. Bazı PDF sayfaları tam görsel kopya değil, işlevsel uyarlamadır.

GitHub'da `islam-ajandasi` deposunun ana dizinine ZIP içindeki dosyaları yükleyin. ZIP klasörünü tek başına yüklemeyin. Önce JSON yedeği alın.
